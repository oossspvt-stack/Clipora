# Clipora visual guide

[Open the website preview](https://oossspvt-stack.github.io/Clipora/) · [Open the studio preview](https://oossspvt-stack.github.io/Clipora/app/) · [Telegram @BMG009](https://t.me/BMG009)

These images are captured from Clipora's actual frontend. The public design preview uses empty example data and does not process videos, connect accounts, or save settings. Run the Python application for those features.

## 1. Open Clipora

The landing page introduces video and live-stream clipping. Open the studio to start.

![Clipora landing page](https://oossspvt-stack.github.io/Clipora/screenshots/01-landing.png)

## 2. Open your studio

Home shows the video input, activity, creators, and posting queue. In the installed application, open Settings → AI to select your provider and save your own API key.

![Clipora studio home](https://oossspvt-stack.github.io/Clipora/screenshots/02-studio.png)

## 3. Add a video

Paste a supported video link or upload your own file. Nothing should start until you press Make clips.

![Video import controls](https://oossspvt-stack.github.io/Clipora/screenshots/03-import-video.png)

## 4. Choose clipping options

Expand the options to choose caption style, layout, and available clip settings. Then press Make clips in the running application.

![Clip settings and caption options](https://oossspvt-stack.github.io/Clipora/screenshots/04-clip-options.png)

## 5. Review videos and clips

All videos holds imported videos and recordings. After real processing finishes, open a video to preview, edit, and download its clips. The empty state below is shown before any video has been processed.

![All videos before the first import](https://oossspvt-stack.github.io/Clipora/screenshots/05-all-videos.png)

## 6. Add a creator for live clipping

New creator opens the creator setup form. In the running app, add the creator's channel and configure recording and posting preferences.

![Creator setup form](https://oossspvt-stack.github.io/Clipora/screenshots/06-new-creator.png)

## 7. Shared-server sign-in

The local installation opens without sign-in by default. Enable accounts for a shared server; visitors then use the account pages.

![Account sign-in page](https://oossspvt-stack.github.io/Clipora/screenshots/07-account-page.png)

## 8. License and contact

The license page is available from the website. For contact, use the Telegram icon and @BMG009.

![Clipora license page](https://oossspvt-stack.github.io/Clipora/screenshots/08-license.png)

## After processing in the running application

1. Open a completed video and play a clip.
2. Adjust the trim, hook, title, caption style, or layout and re-make the clip when needed.
3. Download the finished video.
4. To publish, connect your social accounts in Settings and use the queue or posting controls.

Screenshots of these result-dependent steps will be added after a real video has completed the full processing flow. The preview does not fabricate completed jobs or published posts.
